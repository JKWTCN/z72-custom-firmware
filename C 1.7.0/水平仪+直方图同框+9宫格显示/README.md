# 水平仪+直方图同框+9宫格显示

适用于 Nikon Z7 II 原厂 C1.70 整包固件。此文件夹的 `patch.py` 独立运行，只生成此版本；仅依赖 Python 3 标准库。

在当前文件夹的 PowerShell 中运行：

```powershell
& 'C:\Users\15056\AppData\Local\Programs\Python\Python312\python.exe' .\patch.py 'D:\Temporary\2610\24\z72\Z7_2_0170.bin'
```

默认在脚本所在文件夹生成 `Z7_2_0170.bin`。可用 `-o 'D:\其他目录\Z7_2_0170.bin'` 指定新输出文件；拒绝覆盖已有文件，拒绝将输入作为输出。

- 原厂整包：48,494,024 字节，SHA256 `fc0e94f57500a1f0e287c6b9a036c81a5ffceccb8432a377d645b3fa35a19b6a`。
- 修改整包：48,494,092 字节，SHA256 `d96281f3fc0ce345f2aed74491679f5bb95c635ab5756c018ffe5a43e5268474`。
- 修改 master：SHA256 `7a39b3dc22a8669fd130f1ca25125f5f356838ac898943b6a28aae57e8187e92`。

脚本校验原厂整包 SHA256、原厂 master SHA256、修改前字节、修改后 master 和整包 SHA256，并检查成员及容器 CRC、编码往返以及输出文件读回。校验失败会报错退出。

修改两处 DISP 判断、九个直方图可见性掩码，增加 68 字节跳板代码。另将三条原厂网格配置记录中的横、竖线数从 3 改为 2，共六个 16 位字段，得到两横两竖九宫格；通过原厂 d10「构图网格显示」开启，沿用原厂像素对齐。

只修改 master，其他四个成员逐字节保留。重新计算 master 与容器 CRC，并使用此前已验证的对应候选整包的固定 20 字节更新摘要。此摘要仅适用于脚本生成的精确内容；更改补丁后必须重新构建和验证，不能仅修改 SHA256 常量。本脚本不包含私有签名材料，也不提供任意固件签名功能。

**本版本已由项目提供者在本人使用的 Nikon Z7 II 上成功刷入，并完成实机验证。** 脚本输出与对应实机验证固件逐字节一致，固件版本字符串仍为 C1.70。脚本只在本地生成文件，不连接或刷写相机。
