# Nikon Z7 II 自定义固件补丁

基于 Nikon Z7 II 原厂 **C1.70** 固件的实验性补丁，提供「水平仪＋直方图同屏」「同屏＋九宫格」和「同屏＋九宫格＋STA 5 GHz」三个独立版本。每个版本文件夹中的 `patch.py` 仅生成该版本的固件。

> **刷机有风险，请谨慎操作。**
>
> 本项目为非官方实验性修改，与 Nikon 官方无关。刷入自定义固件可能导致相机无法启动、功能异常，或无法通过菜单恢复，需要维修处理。目前没有经过验证的可靠救砖流程。
>
> **SHA256、CRC 校验通过只说明文件符合预期，不保证刷入安全或所有功能正常。** 请勿用于无法承担停机或损坏风险的设备。决定刷入前，请充分理解风险；保留原厂固件不代表故障后一定能够回刷恢复。升级过程中应确保移除副厂镜头，供电稳定，避免关机、断电或移除存储卡。

## 适用范围

- 机型：**Nikon Z7 II**。
- 输入：未经修改的原厂 **C1.70 `Z7_2_0170.bin`** 整包固件，具体身份由下方 SHA256 确认。
- 运行环境：Python 3，仅使用标准库，无须安装第三方依赖。
- 其他机型、其他版本，以及已经修改过的固件均不适用。

## 生成固件

自行准备原厂固件。在项目根目录打开 PowerShell，选择所需版本运行。将命令中的原厂固件路径替换为实际位置；Python 安装在其他位置时也需相应修改。

**水平仪＋直方图同框：**

```powershell
& 'C:\Users\15056\AppData\Local\Programs\Python\Python312\python.exe' '.\C 1.7.0\水平仪+直方图同框\patch.py' 'D:\firmware\original\Z7_2_0170.bin'
```

**水平仪＋直方图同框＋九宫格：**

```powershell
& 'C:\Users\15056\AppData\Local\Programs\Python\Python312\python.exe' '.\C 1.7.0\水平仪+直方图同框+9宫格显示\patch.py' 'D:\firmware\original\Z7_2_0170.bin'
```

**水平仪＋直方图同框＋九宫格＋STA 5 GHz：**

```powershell
& 'C:\Users\15056\AppData\Local\Programs\Python\Python312\python.exe' '.\C 1.7.0\水平仪+直方图同框+9宫格显示+STA 5GHz\patch.py' 'D:\firmware\original\Z7_2_0170.bin'
```

默认在所选脚本所在文件夹生成 `Z7_2_0170.bin`。可添加 `-o 'D:\目标目录\Z7_2_0170.bin'` 指定输出位置，目标目录需已存在。

脚本拒绝覆盖已有文件，也拒绝将原厂输入文件作为输出。发生校验错误时，请检查输入文件和版本，不要跳过校验或修改哈希常量。脚本只在本地生成文件，不连接或刷写相机。

## 修改范围与验证状态

三个版本均只修改整包中的 master，其他四个成员逐字节保留。同屏补丁修改两处 DISP 判断及九个可见性掩码，增加 68 字节跳板；九宫格版本额外修改六个网格线数参数。STA 5 GHz 版本在同屏＋九宫格基础上，将 22 个有效无线国家配置项的国家码及修订号改为 `US/-1`，保留配置索引和无效项；实际改变 132 字节表数据并重新计算 CRC，不增加 Wi-Fi 驱动或代码。相机显示的固件版本仍为 **C1.70**，不能仅凭版本页区分原厂与修改版。

**三个版本均已由项目提供者在本人使用的 Nikon Z7 II 上成功刷入，并完成实机验证。** STA 5 GHz 版本的测试反馈与图片见上文。验证范围为该设备上实际测试的使用场景，不代表其他机身、长期稳定性或 LCD、EVF、HDMI 全部场景的兼容性均有保证，刷机仍需谨慎。

三个脚本的输出均已与对应实机验证固件逐字节比较一致，并验证会拒绝错误输入及覆盖已有文件。
